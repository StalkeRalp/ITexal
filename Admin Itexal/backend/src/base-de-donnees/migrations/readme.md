# Migrations Base de Données ITexal

Ce dossier contient les fichiers de migration de la base de données PostgreSQL ITexal.

## Commandes à exécuter plus tard :
- Générer une migration : `npm run migration:generate -- -n NomMigration`
- Exécuter les migrations : `npm run migration:run`
- Annuler la dernière migration : `npm run migration:revert`
